# Embedded dependencies

The firmware uses source snapshots from the following upstream projects:

- [STM32F4 HAL Driver](https://github.com/STMicroelectronics/stm32f4xx_hal_driver), commit `1f6451c3e077`.
- [CMSIS Device F4](https://github.com/STMicroelectronics/cmsis_device_f4), commit `9192c7b9df75`.
- [CMSIS Core](https://github.com/ARM-software/CMSIS_5), commit `55b19837f570`.

The upstream license and notice files are retained in each dependency directory.
